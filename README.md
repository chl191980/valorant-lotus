# 无畏契约 · 莲花古城 皮肤体验（网页版 / 适配手游）

### 🎮 在线直接玩 → **https://chl191980.github.io/valorant-lotus/**

> 手机浏览器打开即可，横屏体验最佳。电脑端支持 WASD + 鼠标。
> 仓库：https://github.com/chl191980/valorant-lotus

一个可以 **在手机浏览器里直接玩** 的「无畏契约」风格第一人称打靶/死斗小游戏：
地图是 **莲花古城 LOTUS**（A / B / C 三个包点 + 中路水池 + 旋转门），
武器是 **暴徒 Vandal（AK）** 和 **幻影 Phantom（M4）**，
并且收录了这两把枪 **全部官方皮肤与配色变体（211 款枪皮 / 495 种配色）**。

> 打开方式：用手机浏览器打开本目录下的 `index.html` 即可（不需要联网，枪皮图都在 `assets/` 里）。
> 建议横屏游玩。

---

## 一、怎么玩

| 平台 | 操作 |
| --- | --- |
| 手机 | 左手摇杆移动 · 右半屏滑动转视角 · 按住 🔥 开火 · ⟳ 换弹 · 🎯 开镜 · ⤒ 跳 · ⤓ 蹲 · ⇄ 换枪 · 🎨 皮肤 |
| 电脑 | WASD 移动 · 鼠标转视角（点一下画面锁定指针）· 左键开火 · 右键开镜 · R 换弹 · 1 / 2 换枪 · 空格跳 · C 蹲 · Esc 暂停 |

- **靶场练枪**：BOT 静止，被打掉后自动重生，适合试枪皮、练爆头。
- **莲花古城 死斗**：BOT 会巡逻、会追人、会还击，清空一波后进入下一波（越打越多）。
- 打头 **一枪一个**（暴徒 160 伤害），命中会有金色爆头数字和音效；打身体 40，打腿 34。
- 打完一局会显示统计：击杀 / 爆头 / 爆头率 / 命中率 / 总伤害 / 用时。

## 二、枪皮

- 主菜单 → **藏品库**：按暴徒 / 幻影分页，共 **211 款枪皮**（暴徒 106、幻影 105）。
- 每张卡点开可以：
  - 看 **品质**（究极 / 尊贵 / 高级 / 豪华 / 精选）、系列名、等级效果（音效 / 特效 / 动画 / 终结特效 / 形态变换…）
  - 选 **配色变体**（比如掠夺者 4 种配色、源能者 4 种配色）
  - **装备**：马上出现在第一人称视图里
  - **检视**：全屏展示界面（旋转展台 + 光效 + 变体切换）
  - **★ 收藏**：收藏的皮肤会排在列表最前面
- 设置里可以开「击杀自动换皮肤」，每杀一个人自动轮播一款皮肤——最适合一口气看完全部枪皮。
- 皮肤渲染图来自 Riot 官方素材接口（valorant-api.com），已全部下载到本地 `assets/`，断网也能看。

## 三、地图：莲花古城 LOTUS

- **A 包点**（西北，石柱 + 神像 + 木箱）、**B 包点**（中路正北，金纹地砖）、**C 包点**（东北）。
- **中路大厅**：中央是莲花水池（可以走，会减速），四角石柱掩体。
- **A 连接 / C 连接**：各有金色旋转门（只能绕行）。
- **A 大道 / C 大道**：两条长走廊，适合远距离对枪。
- 小地图（左上角）实时显示你的朝向、包点和 BOT 红点。
- 所有墙体/地面都是程序化生成的贴图（砂岩砖、青木漆墙、金门、莲花地纹），带距离雾和天空渐变。

## 四、文件结构

```
valorant-lotus/
├── index.html            入口（结构）
├── css/
│   ├── style.css         主界面 / HUD / 移动端控件
│   └── collection.css    藏品库专用样式
├── js/
│   ├── skins-data.js     211 款枪皮数据（名称/品质/变体/本地图片路径）
│   ├── map.js            莲花古城地图 + 程序化贴图
│   ├── engine.js         光线投射 3D 渲染器（墙/地面/精灵/雾/小地图）
│   ├── audio.js          全程序化音效（枪声/爆头/换弹/环境声，无音频文件）
│   ├── viewmodel.js      第一人称枪身（真实枪皮渲染图 + 后坐力/枪口焰/换弹动作）
│   ├── bots.js           训练 BOT 精灵与 AI
│   ├── game.js           玩法主循环、射击判定、计分、移动端操作
│   ├── collection.js     藏品库 / 变体 / 收藏 / 检视
│   ├── ui.js             界面切换与设置
│   └── main.js           启动引导
└── assets/
    ├── skins/            495 张枪皮配色渲染图（512×128 PNG）
    ├── wall/             皮肤壁纸（详情页背景）
    └── weapons/          暴徒 / 幻影默认外观
```

## 五、设置项

- 灵敏度、开镜灵敏度倍数、视野 FOV、画质（流畅 / 均衡 / 高清）
- 准星颜色 / 间隙 / 长度 / 中心点
- 音量、击杀自动换皮肤、小地图、FPS 显示、命中伤害数字
- 自动开火、「右侧任意位置按住即射击」、左手摇杆反转
- 所有设置与收藏都存在浏览器本地（localStorage）

## 七、说明

- 本项目是**个人练习作品**，与 Riot Games 无关；枪皮名称与数据来自公开的 valorant-api.com。
- 纯前端实现：没有后端、没有第三方库、没有音频/模型文件，音效与地图贴图都是代码实时生成的。
